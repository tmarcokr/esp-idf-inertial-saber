# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. The full text is available at that link and applies to all project spaces, including issues, pull requests and discussions.

## Summary

We want participation in this project to be a harassment-free experience for everyone. In short:

- Be respectful and constructive. Welcome different viewpoints and levels of experience.
- Accept feedback gracefully and focus on what is best for the project.
- Do not harass, insult, demean or discriminate against anyone.
- Do not publish other people's private information without their permission.

Maintainers may remove, edit or reject contributions that do not follow this Code of Conduct, and may temporarily or permanently ban contributors for behavior they consider inappropriate.

## Reporting

To report unacceptable behavior, use GitHub's private reporting from the repository's **Security** tab ("Report a vulnerability") and state that the report concerns the Code of Conduct. For behavior in a public issue or pull request that does not need to stay private, you can also flag it in a [GitHub issue](https://github.com/tmarcokr/esp-idf-inertial-saber/issues).

All reports are reviewed and handled with respect for the privacy of the reporter.
