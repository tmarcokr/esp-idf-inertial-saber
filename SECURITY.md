# Security Policy

## Supported versions

| Version | Supported |
|:--------|:----------|
| 1.0.0 and later | Yes |
| Earlier than 1.0.0 | No |

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's private vulnerability reporting:

1. Open the [repository](https://github.com/tmarcokr/esp-idf-inertial-saber).
2. Go to the **Security** tab.
3. Select **Report a vulnerability** and describe the issue.

Include the firmware version, the hardware board, the ESP-IDF version and the steps to reproduce the problem. You will receive a response through the same private report.

## What not to post publicly

Do not open a public issue, pull request or discussion for a suspected vulnerability. Do not post in public:

- Exploit details or proof-of-concept code before a fix is available.
- Credentials or tokens found in logs or configuration files.
- Contents of `sdkconfig` or serial logs that expose secrets or device identifiers.

Ordinary bugs that are not security-sensitive belong in the normal [issue tracker](https://github.com/tmarcokr/esp-idf-inertial-saber/issues).
